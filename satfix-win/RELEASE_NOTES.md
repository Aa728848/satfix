# 发布说明（Release notes）

这个文件是**发布说明的唯一来源**：`tools/package_release.ps1` 会从它抽出对应版本的
那一节，作为 GitHub Release 的正文。改说明改这里，不要在 GitHub 网页上直接改 ——
否则下次发布时会被覆盖，而且没有版本记录。

## 约定

- 每个版本一节，标题格式 `## v<版本>`，与清单里的 `version` 一致。
- 最新的写在**最上面**。
- 发布流程见 `README.md` 的「发布与自动更新」一节。

## v0.3.0

修掉三个**看得见的坏症状**，都是 mod 把数值堆到极限后游戏自己算崩的。
目标数从 17 增加到 18（新增舰船详情面板的「伤害」）。

### 修了哪些症状

- **护盾上限突然变成 0**。吃了某些堆叠加成之后，护盾那一栏直接归零。
  原因是加成的真值超过了游戏定点格式能表示的上限，游戏在一次乘法里翻负，
  随后被游戏自己的兜底逻辑夹成 0，最终上限 = 0 × 倍率 = 0 —— 倍率再大也没用。
  现在会被检出并改写回「92 万亿游戏单位」这个天花板值。同一类问题在装甲上也可能出现，
  但两个数会不会同时塌，取决于加成落在护盾还是装甲上 —— 实测只有护盾触发，装甲零误报。
- **舰船详情面板的「伤害」显示成负数**（或大到离谱的数）。
  面板那一格是所有武器组件的总和再乘射速加成，一旦射速加成极端大，总和就越界翻负。
  现在这类值会被封顶到同一个天花板。**这只影响面板显示，不影响战斗里的实际伤害** ——
  面板读的那份是临时算出来的，战斗走的是另一条链，读的是武器组件原始值。
- **过一天变慢、流畅度下降**。这一版给热路径做了两处优化：正常舰船跳过多余的校验重算，
  以及把热路径上的内存读换成不再做内核调用的版本。实测每游戏日推进明显变快。

### 这个构建是**回写模式**（REPLACE=1）

检出溢出时会**把 wrap 掉的值改写成饱和值** —— 也就是真正生效的版本。
日志首行会写明：`REPLACE=1  satfix-build-mode:write-back`。

> 影子模式（只检出、不改数值）是**我们自己测试用**的构建，不发布。
> 它对应的 marker 是 `satfix-build-mode:shadow`，日志首行 `REPLACE=0`。

**会修改存档状态**：这是它的目的。首次使用建议先备份存档。

保守原则：**宁可漏报，不可误改**。只在游戏算出来的值本身就明显是错的（负数、
或者该非零却是零）时才动手写回；正常值哪怕与内部重算有出入也只记日志不改。

### 安装

启动器 → 插件 → 安装，或直接解压到
`Documents\Paradox Interactive\Stellaris\plugins\satfix\`。

适配 `stellaris.exe` 构建 `0x6ABEAA3F`（Cygnus v4.5.2）。游戏更新后会被自动跳过，
这是保护而非故障。

### 已知限制

- 只适配上面列出的构建；游戏更新后需要重新确证地址并升版本发布。
- **未与其他插件同时启用测试过**（本机只有 satfix 一个插件）。
- 部分目标只检出、不修改（观测模式），这是有意为之：判据不够硬的地方宁可不改。
- 「伤害」那一格修好后仍是「92 万亿游戏单位」这个上限值 —— 定点格式本身的物理天花板，
  继续往上堆加成只会再次越界。

详见仓库 [README](https://github.com/Aa728848/satfix)。

## v0.2.0

首个发布。Windows 侧 17 个目标实机验证全部装上，Linux 侧 19 个 hook 目标全部覆盖。

### 它做什么

把 Stellaris 的定点算术接上饱和处理。定点数用 `int64` 存、1.0 记作 `100000`，
上限约 9.2e13 游戏单位；mod 堆叠乘法越过之后**不报错**，直接 wrap 成负数 ——
海军容量变负、资源扣成天文数字、外交权重突然为负。

回写路径有端到端验证（同一构建脚本只差一个开关）：

| 构建 | `GetRounded(INT64_MAX)` 返回 |
|---|---|
| shadow | `-92233720368547`（游戏 wrap 后的值，就是那个 bug） |
| **write-back** | `+92233720368547`（**饱和值，被纠正了**） |

一局后期 mod 存档实测：2390 万次调用、0 条真实分歧
（原版量级离阈值差十几个数量级，要看到效果需要 mod 把数值推到 ~9.2e17）。

### 安装

启动器 → 插件 → 安装，或直接解压到
`Documents\Paradox Interactive\Stellaris\plugins\satfix\`。

适配 `stellaris.exe` 构建 `0x6ABEAA3F`（Cygnus v4.5.2）。
